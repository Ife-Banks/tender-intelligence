CHANGES MADE THIS SESSION (4 edits across 2 files)
----------------------------------------------------

1. OCR MULTILINGUAL SUPPORT  [service.py]
   DocumentProcessingConfig.ocr_lang changed from "eng" to "eng+fra+por".
   Effect: Tesseract now covers all three portal languages in a single OCR
   pass. Scanned French and Portuguese annexes no longer produce garbled
   output.

2. PER-SEGMENT LANGUAGE FIELD  [representation.py]
   Added  language: str | None = None  to ExtractedPage and ExtractedSection.
   Updated to_dict/from_dict for both. Updated content_fingerprint.
   Effect: Each PDF page and each DOCX section carries its own language tag.
   Mixed-language documents expose their language distribution at segment
   granularity, not just document level.

3. PER-SEGMENT LANGUAGE DETECTION  [service.py]
   Added _tag_page_languages() and _tag_section_languages() helpers.
   Called in _finalize() for all extracted documents.
   Effect: Language detection runs once per page/section using the existing
   stopword scorer. Segments below the 20-token minimum keep language=None
   (correct metadata, not a gap).

4. CHECKSUM-BASED DEDUPLICATION  [service.py]
   Added hashlib. Two dedup paths:
   - TenderDocumentProcessor.process(): sha256(bytes) keyed _seen dict;
     duplicate paths skip re-extraction and return a filename-stamped copy.
   - DocumentProcessingService.process_tender(): snapshot.checksum keyed
     _seen_checksums; duplicate DB rows get re-stamped DocumentExtraction
     from the prior result and are persisted + included in bundle.
   Effect: ZIP members with identical bytes are extracted once. Duplicates
   still appear in the bundle with their original identity — never silently
   dropped.
